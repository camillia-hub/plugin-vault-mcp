# Vault MCP

Reads HashiCorp Vault. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/vault-mcp

Installs from the Camillia hub as `vault-mcp-5f8c40`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
